# notes/ — kullanıcının kendi notları

Buradaki dosyalar **kullanıcınındır** (sözleşme 1.9, `SYSTEM.md` §11).
Görev değildirler: iş kuyruğunda görünmezler, ID almazlar, durumları yoktur.

Uygulamada bir belgede metin seçip **"Not ekle"** denince buraya yazılır ve
alıntı belgede yeşil işaretlenir. Not silinince işaret de gider.

**Agent:** bu klasördeki dosyaları iş sayma. Okuyabilir, bağlam olarak
kullanabilirsin; taşıma, düzenleme, silme ve görev açma yok. Bir not iş
içeriyorsa kullanıcıya sor.
